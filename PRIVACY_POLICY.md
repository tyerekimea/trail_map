# Privacy Policy

_Last updated: March 29, 2026_

Trail Map processes location and account data to deliver navigation and saved-places features.

## Data Collected

- Account data: name, email, phone (optional)
- Authentication data: hashed password, session tokens
- Usage data: search and navigation events
- Saved places data: place name, address, coordinates, category, notes
- Technical data: device info, app version, IP address, user agent

## How Data Is Used

- Authenticate users and secure accounts
- Sync saved places across devices
- Improve app reliability and analytics
- Detect abuse and protect service integrity

## Data Sharing

- No sale of personal data.
- Third-party processors may be used for hosting, analytics, and maps services.

## Data Retention

- Account and saved place data retained while account is active.
- Logs and analytics retained according to operational needs and legal obligations.

## Security

- HTTPS for API traffic
- JWT-based auth
- Restricted infrastructure access

## User Rights

- Request account data export
- Request account deletion
- Request correction of profile information

## Contact

For privacy requests, contact: `support@traylapps.com`.
